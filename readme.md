🛡️ SecureSphere

SecureSphere is a privacy-focused, anonymous web communication platform designed for temporary private conversations and controlled information sharing.

Users can create temporary rooms, communicate without exposing their normal identity within the application, and control who can participate or share information inside a room.

live web - https://securesphere-cqm7.onrender.com

🔐 Core Features

- 🕵️ Anonymous Communication — Designed to minimize identity exposure inside the application.
- 🌐 Temporary Virtual IP Assignment — Users connected to a room are assigned temporary virtual IP identifiers for the session.
- 🔒 Private Temporary Rooms — Create rooms specifically for temporary communication.
- 🔑 Custom Room Codes — Room creators can choose their own room code.
- 👤 1-to-1 Private Chat — Create a private room for communication between exactly two users.
- 👥 Group Chat — Create controlled group conversation rooms.
- 📤 Share-It Rooms — Create rooms specifically for sharing text-based information.
- 🧑‍💻 Host Controlled Rooms — The room creator acts as the host and controls participation and sharing permissions.
- ✅ Permission Management — The host can grant selected users permission to send or share messages.
- 🚫 Fixed Room Capacity — A room cannot exceed its configured participant limit.
- ⏳ Temporary Sessions — Rooms are designed around temporary communication rather than permanent identities.
- 📱 Web-Based — Accessible directly through a web browser.

💬 1-to-1 Private Chat

SecureSphere provides a dedicated 1-to-1 private room for two users.

The room is limited to the configured two participants, making it suitable for private conversations.

Features include:

- 👤 Two-person communication
- 🔒 Private room
- 🔑 Custom room code
- 🌐 Temporary session identity
- 🚫 No additional users can join once the room is full

«The 1-to-1 room is designed as the most restricted communication mode within SecureSphere.»

👥 Group Chat

SecureSphere also supports controlled group conversations.

The host can create a room with a predefined participant capacity. Only the configured number of users can connect to that room.

The room does not dynamically expand beyond its configured capacity.

Host Controls

The host can:

- Allow users to participate
- Grant messaging/sharing permission
- Control who can send messages
- Manage the room's participation

📤 Share-It

Share-It is a dedicated room type for sharing text-based information with multiple users.

A host can create a Share-It room and distribute its room code to participants.

The host controls who is allowed to publish information in the room.

This can be useful for:

- 📄 Notes
- 🔗 Links
- 📝 Text information
- 📋 Announcements
- 📚 Study material
- 💡 Temporary information sharing

🔢 Controlled Room Capacity

SecureSphere uses predefined room limits.

If a room is configured for a specific number of users, additional users cannot connect after that capacity is reached.

This prevents unexpected users from joining beyond the intended room size.

🏠 Room Creation

Users can create different types of rooms according to their requirements:

Private 1-to-1

For exactly two participants.

Group Chat

For multiple participants with host-controlled permissions.

Share-It

For controlled text-based information sharing with multiple participants.

🔑 Custom Room Codes

Room creators can choose their own room code instead of relying only on an automatically generated identifier.

The room code can then be shared with the intended participants.

🕵️ Temporary Virtual Identity

SecureSphere uses temporary session-based virtual identifiers for connected users.

Instead of exposing a user's normal identity inside the application's communication layer, users can communicate through their temporary session identity.

These identifiers are intended to exist for the duration of the temporary session.

🛡️ Host Permission System

The host has additional control over the room.

Depending on the room type, the host can decide which participants are allowed to send or share information.

This makes SecureSphere suitable for situations where the room owner wants to control communication instead of allowing every participant to publish content.

⚠️ Security Disclaimer

SecureSphere is a privacy-focused communication project, but no web application should be considered automatically 100% anonymous, untraceable, or completely secure.

Network providers, hosting infrastructure, browsers, operating systems, logging systems, and other third-party services may still have visibility into certain network or technical metadata.

The temporary virtual IP/identity system used by SecureSphere should therefore be understood as an application-level privacy mechanism, not as a replacement for a VPN, Tor, or other network-level anonymity system.

Users should avoid sharing sensitive personal information unless they understand the risks associated with the underlying network and infrastructure.
